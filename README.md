# TillyTasky v1

I want to make a productivity tool based on this tool (https://sparkzsz.notion.site/Daily-Momentum-template-d100eda6abc382cba8b181e538da1bdd).

Name the tool “Task Tallier” 

For purpose of this tool, I don’t want it to be based on “Daily Routine” with the same daily automated habits. I want to be like a dopamine-hit of counting how many tasks you can complete in a day, and being able to beat your record from the previous day.

When you add a task, make it a pop-up you type in, or can type in.

Create these task categories that you can filter in the different progress views:

I 320U

I 372

I 320D

ADV 373

Job Applied

Once you make a task complete but clicking the checkmark, animate confetti to appear on screen (like how Canvas does it when you turn in an assignment)

Keep the “Overview” calendar view, and “Progress” view, being able to see a chart of Progress (Average) over time.

Configure a light mode and dark mode. Use “color_scheme” for design reference. Light mode main color: #F7E9B2, dark mode main color: #422F0E
